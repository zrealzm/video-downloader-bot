# Video Downloader Bot

Этот проект реализует бота для Telegram, который позволяет скачивать видео с популярных площадок: **Instagram** (Reels и посты с помощью cookies), **TikTok**, **YouTube Shorts** и **VK**. Бот работает через веб‑хуки, что позволяет разворачивать его на бесплатных хостингах без фоновых workers.

## Функции

- Команда `/start` приветствует пользователя и выводит кнопки «🎥 Скачать видео» и «ℹ️ Помощь».
- Проверка подписки на обязательный канал. Бот не обслуживает пользователей, пока они не подпишутся. Название/ID канала задаётся через переменную окружения `REQUIRED_CHANNEL`.
- Поддержка загрузки с:
  - **Instagram** — используется `yt-dlp` с указанием cookies из файла `cookies.txt`. Так можно скачивать видео из Reels и постов.
  - **TikTok**
  - **YouTube Shorts**
  - **VK**
- Автоматическая проверка размера файла. Видео до **50 МБ** отправляется напрямую в Telegram. Более крупные файлы загружаются на внешний сервис (например, [transfer.sh](https://transfer.sh)) и пользователю отправляется ссылка для скачивания.
- Файлы скачиваются во временную папку `downloads/` и удаляются после отправки.

## Быстрый старт

1. Клонируйте репозиторий и перейдите в каталог:

```bash
git clone https://github.com/<your-username>/video-downloader-bot.git
cd video-downloader-bot
```

2. Создайте виртуальное окружение и установите зависимости:

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

3. Сохраните cookies для Instagram в файл `cookies.txt` в корне проекта. Cookies можно экспортировать с помощью браузерного расширения (например, EditThisCookie) из аккаунта, у которого есть доступ к нужным публикациям. Не коммитьте этот файл в репозиторий!

4. Настройте переменные окружения (можно добавить в `.env` и загружать через [python-dotenv](https://github.com/theskumar/python-dotenv), либо задать в панели хостинга):

| Название переменной    | Описание                                                                    |
|------------------------|------------------------------------------------------------------------------|
| `TELEGRAM_TOKEN`       | Токен вашего бота от [BotFather](https://t.me/botfather)                    |
| `ADMIN_ID`             | Telegram ID администратора (для логирования ошибок)                         |
| `REQUIRED_CHANNEL`     | Юзернейм или ID канала, на который должны быть подписаны пользователи       |
| `FLASK_ENV`            | (необязательно) Окружение Flask (production/development)                    |
| `BASE_URL`             | Публичный URL вашего сервиса (например, `https://mybot.onrender.com`)       |

5. Запустите приложение локально (для тестов можно использовать [ngrok](https://ngrok.com/) для проброса веб‑хука):

```bash
export TELEGRAM_TOKEN=...
export ADMIN_ID=...
export REQUIRED_CHANNEL=@mychannel
export BASE_URL=https://<your-ngrok-url>
python main.py
```

6. Настройте веб‑хук, отправив запрос:

```bash
curl "https://api.telegram.org/bot<TELEGRAM_TOKEN>/setWebhook?url=<BASE_URL>/webhook"
```

Теперь бот готов принимать сообщения!

## Обновление cookies

Если Instagram требует авторизацию, полученные cookies могут устаревать. Чтобы обновить их:

1. Зайдите в Instagram в том же браузере и аккаунте, из которого вы получали cookies.
2. Снова экспортируйте cookies с помощью расширения.
3. Замените содержимое `cookies.txt` в корне проекта актуальными cookies.
4. Сделайте commit (файл включён в `.gitignore`, поэтому вместо этого можно загрузить его через интерфейс хостинга, например, в настройках переменных окружения). После обновления файл появится в рабочей директории контейнера. Некоторые платформы поддерживают механизм secret files — воспользуйтесь им.

## Развёртывание на Render/Railway

1. Создайте новый веб‑сервис в [Render](https://render.com/) или [Railway](https://railway.app/) и привяжите его к репозиторию GitHub.
2. Укажите команду запуска: `python main.py`.
3. Добавьте необходимые переменные окружения: `TELEGRAM_TOKEN`, `ADMIN_ID`, `REQUIRED_CHANNEL`, `BASE_URL`.
4. После деплоя получите публичный URL сервиса и установите веб‑хук через BotFather или запрос `setWebhook`.
